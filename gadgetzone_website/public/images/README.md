# Images pour Bannères HTFasil

## Fichiers PNG à placer ici:

1. **wave-banner.png** - Fiche ondulé pour la transition bannière
   - Taille recommandée: 1920x120px
   - Fond transparent
   - Couleur: #F9FAFB (gris clair)

2. **arrow-shape.png** - Fiche en flèche
   - Taille recommandée: 1920x80px
   - Fond transparent
   - Couleur: #FFFFFF (blanc)

3. **zigzag-shape.png** - Fiche zigzag
   - Taille recommandée: 1920x60px
   - Fond transparent
   - Couleur: #F9FAFB

## Comment utiliser:

Les images sont référencées dans `src/views/HomeView.vue`:

- `/wave-banner.png` - Pour la transition ondulée
- `/arrow-shape.png` - Pour la forme flèche

## Spécifications:

- Format: PNG avec fond transparent
- Résolution: 72dpi (web)
- Compression: Optimisée pour web
- Taille maximale: 200KB par image
